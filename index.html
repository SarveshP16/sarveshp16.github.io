02 // the loop

Ship it. Watch it. Defend it.

The loop I work in, from a commit landing to an alert firing. Delivery and security aren't separate jobs; each stage feeds the next.

  1. Version

    Source control across GitHub and Bitbucket, with branching and review before anything builds.

  2. Build

    Bamboo and Jenkins builds, with configs kept in step as requirements change.

  3. Scan

    Nessus scans and Burp Suite testing, with findings ranked by real risk.

  4. Release

    Change-controlled deploys of code and database scripts through DEV, UAT and PROD.

  5. Monitor

    Grafana dashboards that catch problems early. Downtime down 22%.

  6. Respond

    Splunk and Sentinel alerts, CrowdStrike and Defender EDR, worked through IR playbooks.
